# SpeakNSolve Website

A new SpeakNSolve web app prototype for online speaking, creative writing,
vocabulary, reasoning, demo sessions, workshops and role-based learning
portals.

## Included in this first version

- Public homepage with introduction, course overview, why SpeakNSolve, how the
  program works, testimonials, demo CTA, enroll CTA and WhatsApp contact.
- Course cards with grade groups, skills, duration, timings, pricing and
  group / 1-to-1 options.
- Parent/student and teacher portal previews covering classes, attendance,
  feedback, assignments, resources, certificates and payments.
- Demo booking form, workshop registration cards, resources, progress,
  payments, notifications and admin management sections.
- Branded generated hero image and social preview metadata.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
